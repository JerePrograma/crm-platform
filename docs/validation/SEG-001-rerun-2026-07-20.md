## Causa del bloqueo

El puerto host `127.0.0.1:5432` está ocupado, reservado o bloqueado en Windows. No es un fallo de PostgreSQL dentro de Docker ni del backend.

## Corrección versionada

Se incorporó un puerto host configurable:

```text
POSTGRES_HOST_PORT=55432
DATABASE_URL=jdbc:postgresql://localhost:55432/gestudio_crm
```

Compose publica ahora:

```text
127.0.0.1:${POSTGRES_HOST_PORT}:5432
```

El backend contenedorizado continúa conectándose internamente a:

```text
postgres:5432
```

Los preflight Unix y PowerShell validan:

- presencia del puerto;
- rango 1–65535;
- coincidencia entre `POSTGRES_HOST_PORT` y `DATABASE_URL`;
- guardas de envío cerradas.

## Reejecución obligatoria

1. actualizar `main`;
2. editar `.env` sin reemplazar credenciales;
3. añadir `POSTGRES_HOST_PORT=55432`;
4. cambiar `DATABASE_URL` a puerto `55432`;
5. ejecutar preflight;
6. reconstruir frontend sin caché;
7. reconstruir backend sin caché;
