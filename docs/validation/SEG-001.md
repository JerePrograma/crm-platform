## Causa raíz confirmada

El POM de Spring Boot 4.1.0 incluía directamente:

```text
org.flywaydb:flyway-core
org.flywaydb:flyway-database-postgresql
```

pero no incorporaba el starter de auto-configuración de Flyway de Spring Boot 4. La librería estaba presente, pero no existía un inicializador que ejecutara `migrate()` antes de JPA.
