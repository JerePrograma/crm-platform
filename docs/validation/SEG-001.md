## Hardening posterior

### Puertos y preflight

- PostgreSQL, backend y frontend con puertos host configurables;
- enteros entre 1 y 65535;
- valores distintos;
- publicación solo en loopback;
- `DATABASE_URL` coordinada;
- daemon Docker obligatorio;
- Compose v2 obligatorio;
- red interna sin cambios.

### Stack y evidencia

- builds sin caché por defecto;
- health por servicio;
- smoke host y contenedor;
- transcript local;
- resumen JSON;
- cleanup sin borrar volumen;
- opción explícita para dejar el stack activo.

### Backend verify contenedorizado

```text

scripts/verify-backend-container.sh
```

Incluye Maven verify, Spotless, unit tests, ArchUnit y Testcontainers con código montado en solo lectura.

### Lockfile y npm ci

- generación `--package-lock-only`;
- lifecycle scripts deshabilitados;
- `node_modules` prohibido;
- SHA-256 del lockfile;
- propiedad UID/GID preservada en Unix;
- Dockerfile, CI y Makefile eligen npm ci cuando existe lockfile.
