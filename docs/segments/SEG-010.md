## Frontera de envío

La configuración efectiva permanece:

```text
SENDING_ENABLED=false
SENDING_DRY_RUN=true
SENDING_DAILY_LIMIT=0
SENDING_KILL_SWITCH=true
MESSAGING_REAL_NETWORK_ALLOWED=false
```

La organización no puede volverla permisiva. El backend rechaza/audita el
intento y el entorno domina la base. Los providers reales siguen no conectados.

## Rollback

V13 no se edita. Una aplicación anterior compatible puede ignorar las columnas
y tablas nuevas; cualquier defecto de datos se corrige con migración posterior.
Antes de un futuro despliegue se exige backup verificado. El restore destructivo
requiere confirmación y una base cuyo nombre comience con `crm_restore_`.
