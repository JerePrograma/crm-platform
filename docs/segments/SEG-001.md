# SEG-001 — Vertical slice persistente de prospectos

## Estado

`ACTIVE — IMPLEMENTATION_HARDENED / EXECUTION_VALIDATION_BLOCKED`

No debe marcarse `COMPLETE` hasta observar una ejecución limpia de backend, frontend, Flyway/Testcontainers, Compose e imagen Docker.

## Objetivo

Entregar un recorrido real y seguro desde CSV/XLSX hasta PostgreSQL, con prospectos consultables, exclusiones dominantes, deduplicación, revisión humana, auditoría e interfaz operativa. Ningún envío real forma parte del segmento.
