## Objetivo

Entregar una vertical slice persistente y segura para:

- instituciones;
- contactos y canales;
- prospectos;
- exclusiones dominantes;
- importación CSV/XLSX con preview y ejecución confirmada;
- deduplicación exacta y revisión ambigua;
- auditoría;
- API autenticada;
- interfaz web operativa;
- stack Docker reproducible.

- PostgreSQL como fuente de verdad;
- Flyway y migraciones versionadas;

- métricas y health;
